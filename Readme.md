# foc_pmsm_demo V0.1



## 项目简介

这个仓库记录的是我最近在做的一套有感FOC的示例程序。  
主控用的是 `armfly-v7`，电机是 `2804`，位置传感器用的是 `TLE5012B`，驱动板是找的一块没名字的板子。

这个版本还很早期，目标不是直接做出一套“效果很成熟”的闭环 FOC，而是先把最基础的东西一项项跑通：

- 三相 `PWM` 发波；
- `ADC` 同步采样；
- 编码器机械角读取；
- 按键交互；
- 串口调试输出；
- 电角度零位标定入口。

换句话说，这一版重点是把硬件链路、软件框架和后续迭代的基础先搭起来。

## 这套工程适合谁

如果你正准备自己搭一个有感 FOC 的最小系统，这个工程应该会比较适合你：

- 想先把主控、驱动、采样、编码器这些基础链路打通；
- 想找一个能继续往下改的 FOC 工程骨架；

## 接线说明

这里直接按功能来分，这样更适合照着接，也更方便后面换板子时迁移。

![V7开发板引脚说明](https://img-bed-flyyingpiggy2020.oss-cn-shanghai.aliyuncs.com/img/image-20260330142137566.png)

### 1. 三相 PWM

这一组信号负责把主控的控制量送到驱动板。

从功能关系上看，就是：

- `armfly-v7` 输出三相 `PWM`
- 驱动板接收三相 `PWM`
- 驱动板三相功率输出接到 `2804` 电机三相线

当前代码对应的引脚如下：

| 信号 | MCU 引脚 / 外设 |
| --- | --- |
| `TIM1_CH1` | `PA8` |
| `TIM1_CH1N` | `PK0` |
| `TIM1_CH2` | `PJ11` |
| `TIM1_CH2N` | `PJ10` |
| `TIM1_CH3` | `PJ9` |
| `TIM1_CH3N` | `PJ8` |

补充说明：

- 当前工程软件写的是 `TIM1` 三路互补输出；

- 如果你的驱动芯片内部已经生成互补和死区，也可以只接主通道，不接 `CHxN`；
- 当前样机使用 `TIM1` 中心对齐计数，并通过 `CH4(OC4REF)` 触发 `ADC` 采样；
- 调试测试引脚是 `PJ7`，我这里用它看更新时序。

关于智木创客驱动板的特殊说明：

1. 我的驱动板它不需要互补的6路PWM波，因为它的驱动芯片是IR2103S，只需要三个PWM就行了，芯片自己会有死区。虽然我的软件里面写的是6路互补带死区的PWM波，但是实际上我只用到了主通道。
2. 使用 `TIM1` 中心对齐计数，并通过 `CH4(OC4REF)` 触发 `ADC` 采样；这个方法是为了让低侧采样更加干净，在管子关断的中心时刻采样。但是智木创客的驱动板不是低侧采样的，它使用了`INA4181A3IPWR`这款高共模抑制比的运放。所以这块板子的采样时机不是很重要，它任意时刻采样都是可以的。缺点是硬件成本会比低侧采样高一点。

### 2. 磁性编码器

这一组信号负责读取转子的机械角，当前使用的是 `TLE5012B`。

从功能关系上看，就是：

- `armfly-v7` 通过 `SPI1` 与 `TLE5012B` 通信
- `TLE5012B` 提供电机转子的机械角信息

当前代码对应的引脚如下：

| 信号 | MCU 引脚 / 外设 |
| --- | --- |
| `SPI1_SCK` | `PB3` |
| `SPI1_DATA` | `PB5` |
| `SPI1_CS` | `PG10` |

补充说明：

- 当前编码器是 `TLE5012B`；
- `TLE5012B` 不是标准四线 SPI，这里按单数据线收发方式处理，H7的SPI原生就支持这种半双工模式，可以使用硬件SPI；
- 如果后面换成别的磁编码器，`BSP SPI` 和传感器适配层都要一起改。

### 3. 其他辅助接口

除了上面两类主接口，当前工程里还有这些辅助连接：

| 功能 | MCU 引脚 / 外设 |
| --- | --- |
| `ADC1_INP0 / INP1 / INP2` | `PA0 / PA1 / PF11` |
| `USART1 TX/RX` | `PA9 / PA10` |
| `KEY1` | `PI8` |
| `KEY2` | `PC13` |
| `KEY3` | `PH4` |

## 硬件实现上的几个关键点

### 1. PWM 和 ADC 不是各跑各的

当前工程里：

- 三相 `PWM` 由 `TIM1` 产生；
- 定时器用的是中心对齐计数方式；
- `ADC1` 由 `TIM1` 触发采样；
- 当前代码里用 `CH4(OC4REF)` 作为 `ADC` 触发源。

所以如果你后面自己改时序，先查定时器和采样触发关系，不要只盯着 `ADC` 或 `PWM` 某一个模块看。

### 2. 当前样机做过采样电阻改造

当前样机把采样电阻换成了 `10mΩ`，原智木创客的板卡里的采样电阻是`1mΩ`，因为我要去驱动的电机是`2804` ，电流比较小，为了分辨率所以改了采样电阻 
这个地方复现时一定要注意阻值和功率，否则后面的电流换算就会不对。

### 3. 当前是相电流采样思路

`INA4181A3IPWR`运放放大倍数是100

采样电阻是`10mΩ`

采样的参考电压是`1.65V` ，零电流时在中点附近，正负电流围绕中点摆动。

也就是说，如果`10mΩ`流过`1A`的电流，会产生`10mV`的电压，放大100倍之后，就是1V。

这里的`1V`对应了`1A`的电流。

### 4.CPU资源说明

`PJ7`为调试引脚，接入示波器测量一些运算时间的。

笔者目前PWM开关频率为`8K`，也就是`125us`，目前电机方面的运算，放在DMA中断里面执行。

ADC采样完成的中断触发后，在中断中，读取机械角度，并计算下一次的PWM占空比，并修改CRR值。

笔者测量过，这个过程浮点数运算目前需要`30us`

也就是说，有`90u`s以上的空闲可以执行主循环里面的业务逻辑，完全够用了。

如果要提高开关频率，就需要优化计算方式了。开关频率越快，则计算量越大。但是更高的开关频率，可以实现更好带宽响应的控制效果。

### 4. 标幺化说明

笔者这里的运算，目前采用标幺化+浮点数。

### 验证流程

**先不要上电，验证磁编角度读取是否正确**

仿真观察`g_app_foc.foc`这个结构体

正常情况下：

- 停机状态下长按 `KEY1` 会进入标定；
- 电机会被固定电压矢量锁到一个对齐角；
- 保持一段时间后采样机械角；

标定后的`electrical_angle`将不为0，并且在`FOC_MODE_STOP`时，三相占空比`duty_a/b/c`是0.5。

此时短按 `KEY1`启动电机，此时由于**电机不上电**，用手旋转电机。

如果接了 `VOFA`，目前可以看到：

- 三相 `PWM` 占空比变化，输出一个马鞍波；

确保三相TIM_CH1/2/3没接错之后，再上电验证。
