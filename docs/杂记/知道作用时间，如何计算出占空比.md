**分成六个方向（实际上就是相差120°的三相在α-β坐标系下的表示）**

```matlab
X = K * Ubeta;
Y = K * ((sqrt(3)/2) * Ualpha + 0.5 * Ubeta);
Z = K * (-(sqrt(3)/2) * Ualpha + 0.5 * Ubeta);
```

X,Y,Z,-X,-Y,-Z就是六个矢量，当合成后的目标矢量落在任意一个扇区时，上述任意两个拼接组合而成。

以第一扇区为推导，假设目标矢量落到了(0°~60°)，那么它由矢量V1(处于0°)和矢量V2(处于60°)合成。



作用时长为Ts，归一化为1。

**其中K的数值为`K = sqrt(3) / Udc`，这里的K为什么是这个数值？**

```matlab
K = sqrt(3) / Udc; 
```

三相逆变器中，基础电压矢量的大小为2/3U_{dc}

我们将参考矢量分解到α-β坐标系，计算所有的T1~T6之后，发现都有共同的系数`K = sqrt(3) / Udc` ，为了不重复计算，所以规定了这个系数。



**知道T1和T2之后，如何计算出Ta,Tb和Tc呢？**

知道T1和T2的时间之后还不够，我们实际控制需要知道切换点

```matlab
    % Ta, Tb, Tc 代表在半个载波周期内的切换点
    Ta = (1 - T1 - T2) / 4;
    Tb = Ta + T1 / 2;
    Tc = Tb + T2 / 2;
    
    % 将切换时间转换为实际的等效占空比 (0~1)
    Da = 1 - 2*Ta;
    Db = 1 - 2*Tb;
    Dc = 1 - 2*Tc;
```
