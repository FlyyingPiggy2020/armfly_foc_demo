## 问题一：FOC开环能够运行，但是闭环后震荡。

检查ADC的接线是否正确。

1.锁轴，给虚拟的角度，例如固定当前角度为0。
2.关掉PI直接给V_d=0.12;V_q=0。
3.如果接线正常，理论上应该读到a相电流是一个正数，ib是一个负数幅值为ia的一半。

理论上上面给定的输入，输出应该如下所示：
d=0.12 q=0, theta = 0;
alpha = 0.12, beta=0
a = 0.12 ; b = -0.06; c = -0.06



但是我实际上读到a相的是负数，b相是正数符号反了，大小也反了。可能如下原因导致：

1. 占空比发波设置的不正确
2. PCB板上的电流采样引脚画反了。(笔者买的板子，不可能这个问题)

最后笔者发现自己的引脚C相和A相接反了。杜邦线接线互换后一切正常。





## 问题二：电流闭环后FOC声音比开环时候更加大。

1.设置iq=0，id=0，还是能听到沙沙声。

2.将电流采样滤波，电流滤波前和滤波后的声音对比，能感受到明显的改善。

## 问题三：IQ=0.06时电机才起转，但是IQ=0.03时电机仍然不停止。IQ=0时电机产生震荡。

标准的同步旋转坐标系（$d-q$ 轴）下的电压方程为：

$$V_d = R i_d + L_d \frac{di_d}{dt} - \omega_e L_q i_q$$

$$V_q = R i_q + L_q \frac{di_q}{dt} + \omega_e L_d i_d + \omega_e \lambda_f$$

#### d轴补偿项：

$$\text{Comp}_d = -\omega_e L_q i_q$$

*(作用：抵消 $q$ 轴电流对 $d$ 轴电压的耦合干扰)*

#### q轴补偿项：

$$\text{Comp}_q = \omega_e L_d i_d + \omega_e \lambda_f$$

*(作用：抵消 $d$ 轴电流耦合以及最核心的**反电动势**)*

------

### 2. 参数含义说明

| **符号**    | **含义**         | **单位**  | **备注**                                                     |
| ----------- | ---------------- | --------- | ------------------------------------------------------------ |
| $\omega_e$  | **电角速度**     | rad/s     | $\omega_e = \text{机械转速} \times \text{极对数} \times \frac{2\pi}{60}$ |
| $L_d, L_q$  | 电机电感         | H (亨利)  | 表贴式电机 (SPM) 通常 $L_d = L_q$                            |
| $i_d, i_q$  | 实时电流反馈     | A (安培)  | 通常使用测量值或指令值                                       |
| $\lambda_f$ | **转子磁链常数** | Wb (韦伯) | 与电机的反电动势常数 $K_e$ 直接相关                          |
